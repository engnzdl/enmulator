# Enmulator — Design Spec

## Goal

Cross-platform (Win/Mac/Linux) Android emulator manager with device fingerprinting, root control, and headless API. Open-source alternative to MuMuPlayer Pro, built on Android SDK AVD.

## Architecture

```
┌──────────────────────────┐
│  Tauri Web Frontend      │  React/Vue + TypeScript
│  - Device list & wizard  │
│  - Drag-drop APK         │
│  - Live log viewer       │
└─────────┬────────────────┘
          │ IPC (invoke/event)
┌─────────▼────────────────┐
│  Rust Backend            │
│  ├─ avd_manager          │  avdmanager CLI wrapper
│  ├─ emulator             │  emulator process manager
│  ├─ adb_bridge           │  ADB command interface
│  ├─ root_engine          │  rootAVD integration
│  ├─ fingerprint          │  build.prop / IMEI mods
│  ├─ proxy                │  per-device MITM proxy
│  └─ api_server           │  Headless REST API (Actix)
└─────────┬────────────────┘
          │
┌─────────▼────────────────┐
│  Android SDK             │
│  system-images/ emulator │
│  platform-tools/ (adb)   │
└──────────────────────────┘
```

## IPC Commands (Tauri invoke)

```
// Device Management
list_devices() -> Vec<Device>
create_device(name, profile_id, api_level, root) -> Device
start_device(id) -> u16
stop_device(id)
delete_device(id)
clone_device(source_id, target_name) -> Device

// Fingerprint
apply_profile(device_id, profile_id)
list_profiles() -> Vec<FingerprintProfile>
save_profile(profile: FingerprintProfile)
delete_profile(profile_id)

// ADB & Root
adb_shell(device_id, cmd) -> String
install_apk(device_id, apk_path) -> bool
toggle_root(device_id, enable) -> bool
push_file(device_id, local_path, remote_path)
pull_file(device_id, remote_path, local_path)

// Proxy
start_proxy(device_id, port) -> u16
stop_proxy(device_id)

// Recording
start_recording(device_id) -> String    // Returns output path
stop_recording(device_id) -> String     // Returns output path

// Log
stream_logcat(device_id) -> Event       // Tauri event stream

// Clipboard
sync_clipboard(device_id, direction)    // "host_to_device" | "device_to_host"

// Headless API
start_api_server(port) -> u16
stop_api_server()

// SDK
detect_sdk() -> Option<String>
list_available_images() -> Vec<SystemImage>
install_system_image(api_level, abi)
```

## REST API (Headless Mode)

```
POST   /api/devices                    → Create device
GET    /api/devices                    → List all devices
POST   /api/devices/:id/start          → Start device
POST   /api/devices/:id/stop           → Stop device
POST   /api/devices/:id/clone          → Clone device
DELETE /api/devices/:id                → Delete device
POST   /api/devices/:id/adb            → Run ADB command { "cmd": "..." }
POST   /api/devices/:id/apk            → Install APK (multipart)
GET    /api/devices/:id/logcat         → Live log (SSE)
POST   /api/proxy/:id/start            → Start proxy
POST   /api/proxy/:id/stop             → Stop proxy
POST   /api/recording/:id/start        → Start recording
POST   /api/recording/:id/stop         → Stop recording
GET    /api/profiles                   → List profiles
POST   /api/profiles                   → Create profile
```

## Implementation Phases

### Phase 1 — Core MVP
- Tauri project scaffold + React UI shell
- SDK auto-detection (Win/Mac/Linux paths)
- `avd_manager`: create/list/delete AVDs via CLI
- `emulator`: start/stop with process lifecycle
- Device list UI with start/stop buttons
- `~/Code/enmulator/devices/` directory structure

### Phase 2 — Fingerprinting & Root
- `fingerprint`: Profile system, apply to device via ADB
- `root_engine`: rootAVD integration, one-click root toggle
- `adb_bridge`: ADB command execution, APK install
- Profile picker UI in create wizard
- Clone device functionality

### Phase 3 — Power Features
- `proxy`: Per-device MITM proxy (mitmproxy embedded)
- `api_server`: Headless REST API with Actix
- Drag-and-drop APK install (Tauri drag event → Rust handler)
- File explorer (ADB push/pull wrappers)

### Phase 4 — Polish
- Screen recording (adb screenrecord + ffmpeg)
- Clipboard sync (adb shell cmd clipboard)
- GPS simulation (emulator console `geo fix`)
- Live logcat stream (SSE to frontend)

## Edge Cases

- **SDK not found**: Show setup wizard with download links
- **System image missing**: Auto-download via sdkmanager
- **Device port conflict**: Auto-increment port pairs (5554, 5556, 5558...)
- **AVD already running**: Skip, show "already running" status
- **rootAVD fails**: Fallback to system root (eng build), show warning
- **Emulator crash**: Detect exit code, offer restart
- **Disk space**: Check before creating device, warn if < 10GB
- **Cross-platform paths**: Use `dirs` crate for OS-specific directories
- **Simultaneous API + GUI**: API server runs in separate thread, no conflicts

## Testing Strategy

- Unit tests for each Rust module (avd_manager, fingerprint, etc.)
- Integration tests with real `adb` commands in CI (GitHub Actions with Android SDK)
- UI tests with Tauri's WebDriver support
- Cross-platform CI matrix: `ubuntu-latest`, `macos-latest`, `windows-latest`
